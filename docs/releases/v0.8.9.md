# Zibaldone v0.8.9

## 這版重點

- 安裝包瘦身：sidecar 內的 OpenCV 由完整版改為 headless 版（RapidOCR 只做
  靜態圖片辨識，用不到 Qt 圖形介面與影片編解碼元件），移除約 37MB 無用內容。
- 功能、辨識品質與操作介面完全不變；本地免金鑰 OCR 照舊開箱即用。

## 驗證

- Backend unit tests：354 passed，1 skipped（CI 於 headless OpenCV 環境執行）。
- 凍結版 sidecar 對無字幕硬字幕影片實跑本地 RapidOCR：6 幀取樣、品質判定
  content_candidate，正確讀出硬字幕。
- Windows 與 macOS 安裝包由 `v0.8.9` release workflow 在原生 GitHub runner
  建置，並 smoke test 實際打包的 sidecar。
