# Zibaldone v0.8.4

## 這版重點

- 修正 macOS Apple Silicon 發行包大小 gate：保留 Windows 110 MB 硬上限，macOS 改為 200 MB 硬上限，避免把不同平台的壓縮特性誤判為建置失敗。
- macOS 本版預期約 177–182 MB，Windows 約 96 MB；這是因為安裝包包含本機 FastAPI sidecar，不包含 Gemma 模型。
- 其餘功能與 v0.8.3 相同，包括 CLI 勾選後明確提示必須儲存、無金鑰時可產生待人工整理草稿，以及 Windows 不跳出終端機視窗。

## 下載與安裝

| 平台 | 安裝檔 |
|------|--------|
| macOS Apple Silicon | `Zibaldone_0.8.4_aarch64.dmg` |
| Windows x64 | `Zibaldone_0.8.4_x64-setup.exe` |

Intel Mac 與 Linux 目前無公開安裝檔（Linux 請依開發文件自行建置）。

## ⚠️ macOS 使用者注意

安裝檔未經 Apple Developer ID 簽章與公證。打開 DMG、把 Zibaldone 拖進
「應用程式」後，在終端機執行一次以下指令，移除這個 App 的隔離標記
（否則 Gatekeeper 會顯示「App 已損毀，無法打開」）：

```sh
xattr -r -d com.apple.quarantine "/Applications/Zibaldone.app"
```

請只對這個固定路徑執行；不要關閉整台電腦的 Gatekeeper。

## 驗證下載檔案

所有安裝檔的 SHA-256 分別列在 `SHA256SUMS-macos-latest.txt` 與
`SHA256SUMS-windows-latest.txt`。在下載目錄（例如 `~/Downloads`）執行，
以 macOS DMG 為例：

```sh
cd ~/Downloads
grep 'Zibaldone_0.8.4_aarch64.dmg' SHA256SUMS-macos-latest.txt | sed 's|dmg/||' | shasum -a 256 -c -
```

輸出 `Zibaldone_0.8.4_aarch64.dmg: OK` 即表示檔案完整，再依上方步驟安裝。
Windows（PowerShell）：比對 `(Get-FileHash .\Zibaldone_0.8.4_x64-setup.exe).Hash`
與 `SHA256SUMS-windows-latest.txt` 內的雜湊一致即可。Windows 未使用
Authenticode，SmartScreen 警告仍是預期風險。
