# Zibaldone v0.8.6

## 這版重點

- 修正 macOS 更新後遺留的舊版 Python sidecar 佔用 `127.0.0.1:8766`，造成新版本後端無法啟動的問題。
- 僅在啟動命令與 `/api/health` 回應都符合 Zibaldone 指紋時，才回收舊版 sidecar；不會誤殺其他 Python 或 HTTP 程序。
- 後端成本摘要無法讀取時，介面改為明確顯示「狀態未知」，不再錯誤顯示額度內。
- Windows 與 macOS release workflow 均會 smoke test 實際打包的 sidecar，包含健康檢查與受保護成本 API。

## 下載與安裝

| 平台 | 安裝檔 |
|------|--------|
| macOS Apple Silicon | `Zibaldone_0.8.6_aarch64.dmg` |
| Windows x64 | `Zibaldone_0.8.6_x64-setup.exe` |

Intel Mac 與 Linux 目前無公開安裝檔（Linux 請依開發文件自行建置）。

## ⚠️ macOS 使用者注意

安裝檔未經 Apple Developer ID 簽章與公證。打開 DMG、把 Zibaldone 拖進
「應用程式」後，在終端機執行一次以下指令，移除這個 App 的隔離標記
（否則 Gatekeeper 會顯示「App 已損毀，無法打開」）：

```sh
xattr -r -d com.apple.quarantine "/Applications/Zibaldone.app"
```

請只對這個固定路徑執行；不要關閉整台電腦的 Gatekeeper。

## 驗證下載檔案

所有安裝檔的 SHA-256 分別列在 `SHA256SUMS-macos-latest.txt` 與
`SHA256SUMS-windows-latest.txt`。在下載目錄（例如 `~/Downloads`）執行，
以 macOS DMG 為例：

```sh
cd ~/Downloads
grep 'Zibaldone_0.8.6_aarch64.dmg' SHA256SUMS-macos-latest.txt | sed 's|dmg/||' | shasum -a 256 -c -
```

輸出 `Zibaldone_0.8.6_aarch64.dmg: OK` 即表示檔案完整，再依上方步驟安裝。
Windows（PowerShell）：比對 `(Get-FileHash .\Zibaldone_0.8.6_x64-setup.exe).Hash`
與 `SHA256SUMS-windows-latest.txt` 內的雜湊一致即可。
