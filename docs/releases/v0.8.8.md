# Zibaldone v0.8.8

## 這版重點

- 修正 Windows 封裝版無字幕影片的 ASR／OCR 皆失敗的問題：
  - ASR：設定頁與影片流程內建一鍵下載預編譯 whisper.cpp 引擎＋base 模型
    （Windows／Linux；macOS 維持原始碼建置），不再需要自行準備編譯工具鏈。
  - OCR：封裝 sidecar 現在正確打包 RapidOCR 模型與 onnxruntime，本機免金鑰
    OCR 開箱即用；暫存目錄不再寫死 `/tmp`。
  - 後端未預期錯誤改為回傳可讀訊息，不再只顯示「Failed to fetch」。
- 影片 ASR 預設模型由 small 改為 base（small 需另行手動下載，base 才是
  一鍵安裝實際提供的模型）。
- 雲端 OCR 產出的字幕文字不再夾雜 raw JSON 殘片。
- 無字幕影片的雲端 OCR 需明確同意才上傳取樣幀；sidecar 未就緒時介面會
  引導重啟而非直接失敗。

## 驗證

- Backend unit tests：354 passed，1 skipped（含 ASR runtime、OCR 文字清理
  新增測試）。
- Frontend unit tests：52 passed；Playwright E2E 全數 passed。
- 真機瀏覽器流程驗證：同一無字幕硬字幕影片，本機 RapidOCR、雲端 OCR、
  whisper.cpp ASR 三條路徑皆成功產出可用文字。
- Windows 與 macOS 安裝包由 `v0.8.8` release workflow 在原生 GitHub runner
  建置，並 smoke test 實際打包的 sidecar。
