# Zibaldone v0.8.7

## 這版重點

- 修正 macOS／Windows 封裝版在無字幕影片第一次下載 ffmpeg／ffprobe 時，可能因找不到系統 CA 憑證鏈而顯示 `CERTIFICATE_VERIFY_FAILED`、無法繼續本機 ASR／OCR 的問題。
- 媒體工具下載沿用 app 已隨 sidecar 打包的 certifi CA bundle；TLS 主機名與憑證驗證仍保持開啟。
- 下載來源、pinned SHA-256、原子寫入與既有操作介面均維持不變。

## 驗證

- ffmpeg runtime 離線回歸測試：2/2 passed，包含 `check_hostname=True` 與 `CERT_REQUIRED`。
- Backend unit tests：338 passed，1 skipped。
- PR CI：backend、frontend、Playwright E2E、product-readiness 全部 passed。
- Windows 與 macOS 安裝包由 `v0.8.7` release workflow 在原生 GitHub runner 建置，並 smoke test 實際打包的 sidecar。
