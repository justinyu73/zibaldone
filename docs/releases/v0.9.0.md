# Zibaldone v0.9.0

## 這版重點

- 安裝包大幅瘦身（sidecar 本體縮小約 42%）：本地免金鑰 OCR 引擎
  （RapidOCR）不再內建於安裝包，改為首次使用時一次性下載（約 150MB，
  與語音轉錄引擎相同的下載模式，sha256 驗證）。
- 無字幕影片「讀畫面硬字幕（OCR）」在無 API 金鑰時，會引導下載本機 OCR
  引擎；有 OpenAI 金鑰時可照舊直接使用雲端 OCR，不需下載。
- 掃描型 PDF 的本地 OCR 同樣改用此引擎包。
- 功能與辨識品質不變；下載後的 OCR 完全離線、免金鑰。

## 驗證

- Backend unit tests：360 passed，1 skipped（含 OCR 引擎包下載器與
  subprocess 客戶端新測試）。
- Frontend unit tests：52 passed；Playwright E2E 全數 passed。
- 引擎包端到端：selftest、真實截圖辨識、無金鑰後端跑完整 OCR 流程皆通過。
- Windows 與 macOS 安裝包及三平台 OCR 引擎包由 `v0.9.0` release workflow
  在原生 GitHub runner 建置，並 smoke test 實際打包的 sidecar。
